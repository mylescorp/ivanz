Getting started

  1. Create a Convex account and run npx convex dev at the project root.
  2. Copy admin/js/config.example.js to admin/js/config.js with your Convex URL.
  3. Deploy the schema shell with npx convex deploy.
  4. Phase 2 wires Convex Auth — login buttons activate after that.
